# API Specification (v1)

Base path: `/api/v1`. JSON unless stated. OpenAPI is generated by FastAPI at `/api/v1/openapi.json` and is the source of truth once implemented; this document is the design.

## 1. Conventions

- **Auth**: `Authorization: Bearer <JWT>` (OIDC provider such as Keycloak, or the built-in local login for single-tenant deployments). Roles: `viewer` (read data, own layers), `editor` (+ analysis, export), `admin` (+ manage connections/users).
- **Coordinates**: GeoJSON, EPSG:4326, `[lon, lat]`. `bbox=minLon,minLat,maxLon,maxLat`.
- **IDs**: UUIDs for app objects; PostgreSQL objects addressed by `{schema}.{table}`.
- **Pagination**: `limit` (default 100, max per endpoint), `offset` or `after` (keyset cursor). Responses carry `page: {limit, offset, nextCursor, total?}`.
- **Content negotiation**: `Accept: application/geo+json` (default for features), `application/vnd.apache.arrow.stream` (large tabular/H3), `application/vnd.mapbox-vector-tile` (tiles). gzip/br compression.
- **Rate limiting**: per user and per connection; `429` with `Retry-After`.
- **Versioning**: path prefix; additive changes only within v1.

## 2. Errors

```json
{ "error": { "code": "invalid_filter", "message": "Unknown column 'popp'", "details": {"column":"popp"}, "requestId":"…" } }
```

| HTTP | code | When |
|---|---|---|
| 400 | `bad_request` | malformed params |
| 401 | `unauthenticated` | missing/expired token |
| 403 | `forbidden` | no role / no grant on connection |
| 404 | `not_found` | connection/table/layer missing |
| 409 | `conflict` | duplicate name |
| 413 | `payload_too_large` | upload or geometry too big |
| 422 | `invalid_filter` / `validation_error` | schema or filter grammar failure |
| 429 | `rate_limited` | |
| 500 | `internal_error` | no internals leaked |
| 502 | `db_unavailable` | connection to user DB failed |
| 504 | `query_timeout` | statement timeout |

## 6. Features (client-sized data)

`GET /connections/{id}/tables/{schema}/{table}/features`

| Param | Meaning |
|---|---|
| `geometryColumn` | default = first geometry column |
| `bbox` | viewport filter (required when `estimatedRows` > `maxFeaturesNoBbox`) |
| `columns` | comma list of attributes to include |
| `filter` | JSON filter (see DATABASE_INTEGRATION.md §4), URL-encoded; or `POST …/features/query` with the same in the body for long filters |
| `simplify` | tolerance in degrees or `auto` (from `zoom`) |
| `zoom` | for `auto` simplification |
| `limit` / `after` | pagination, `limit ≤ maxFeatures` |
| `format` | `geojson` (default), `arrow` |

Response (GeoJSON):
```json
{ "type":"FeatureCollection","features":[{"type":"Feature","id":1,"geometry":{…},"properties":{…}}],
  "page":{"limit":10000,"nextCursor":null},"truncated":false }
```

`POST …/features/query` accepts `{bbox, columns, filter, spatial:{op:'intersects',geometry}, limit}`.
`GET …/features/{id}` returns one feature with **all** attributes (used by the inspector after tile clicks).

## 8. H3

| Method | Path | Description |
|---|---|---|
| GET | `/connections/{id}/tables/{schema}/{table}/h3/cells` | Read an existing H3 table: params `column`, `resolution` (target), `bbox`, `value` (column), `agg`, `filter`, `maxCells`. Returns `{resolution, nativeResolution, cells:[{h3:"89…",value:12.3,count:4}], stats:{min,max,mean,quantiles}, truncated}` |
| GET | `/connections/{id}/tables/{schema}/{table}/h3/aggregate` | Aggregate a **geometry/point** table into H3: `resolution`, `bbox`, `value`, `agg ∈ count,sum,avg,min,max,median`, `filter`, `weight` |
| POST | `/h3/polyfill` | `{geometry, resolution, mode:'center'|'full'|'overlap'}` → `{cells:[…]}` (cap `maxCells`) |
| POST | `/h3/cells/info` | `{cells:[…]}` → `[{h3,resolution,center,boundary,area_km2,isPentagon,parent}]` |
| POST | `/h3/cells/children` | `{cell, resolution}` → cells (Δ ≤ 4 enforced) |
| POST | `/h3/cells/export` | `{cells,format:'csv'|'geojson'}` |
| GET | `/connections/{id}/tables/{schema}/{table}/h3/resolutions` | distinct resolutions present, counts |

Responses default to JSON; `Accept: application/vnd.apache.arrow.stream` for >100k cells. The server may return a coarser resolution than requested when `maxCells` would be exceeded and says so in `resolution`.

## 9. Analysis (server-side, PostGIS/Python)

All accept a layer reference (`{connectionId,schema,table,filter}`) or inline GeoJSON (size-capped) and return a GeoJSON FeatureCollection (temporary result, optionally `?asLayer=true` registers an ephemeral source).

| Method | Path | Body | Backend |
|---|---|---|---|
| POST | `/analysis/buffer` | `{input, distance, unit:'m'|'km', segments, dissolve}` | PostGIS (`geography` / UTM) |
| POST | `/analysis/intersection` | `{a, b}` | PostGIS |
| POST | `/analysis/union` | `{input, dissolveBy?}` | PostGIS `ST_Union` aggregate |
| POST | `/analysis/clip` | `{input, clip}` | PostGIS |
| POST | `/analysis/nearest` | `{origin, target, k, maxDistance}` | PostGIS KNN `<->` |
| POST | `/analysis/within-distance` | `{input,point,distance}` | PostGIS |
| POST | `/analysis/spatial-join` | `{left,right,predicate,aggregations}` | PostGIS |
| POST | `/analysis/stats` | `{input, column, groupBy?}` | PostGIS / pandas |
| POST | `/analysis/jobs` | any of the above, async | returns `202 {jobId}`; poll `GET /analysis/jobs/{id}`; Python worker (Phase 9) |

Browser-side (not API): measure distance/area, buffer/union/intersect of small drawn geometries (Turf, < ~5k vertices), point-in-polygon selection for loaded data. Rule: *anything that must see the whole database table runs on the server.*

## 12. Export

`POST /export` `{source|selection, format:'geojson'|'csv'|'gpkg'|'fgb'|'shp', filter, bbox, crs}` → streamed file or `202` job. Row caps and timeouts apply; `shp` via GDAL/pyogrio.

## 13. Validation & security rules (all endpoints)

- Pydantic models with `extra='forbid'`; bounds on every numeric parameter (zoom 0-24, resolution 0-15, limit, distance).
- Geometry inputs: valid GeoJSON, max vertices, max bytes, `ST_IsValid` check, coordinates range check.
- Identifiers validated against the catalogue; filters via whitelist grammar; no raw SQL anywhere.
- CORS allow-list; CSRF only relevant if cookie auth is used.
- Per-request timeouts and cancellation: when the client aborts, the backend cancels the query (`pg_cancel_backend` via psycopg cancel).
